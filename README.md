# PhishingAndSpamDomains
My personal block list containing spam, scam and phishing websites and some other privacy nightmares. 
I did not include social media blockers or many advertisement providers on this list, because this list mainly focuses on scam/spam/fraud/phishing and other nasty stuff.
The domains on this list are really, really evil.

The contents of this list is gathered over time using a very old hotmail address that has been a victim of dozens of data breaches and leaks. 
Every spam mail that I received the last 8 or so years, I scan using [urlscan.io](https://urlscan.io) . 
After the scan, I block the entire chain of domains that are called and redirected to from any link in that spam mail using my own [Firefox](https://github.com/VanHamsteren/SecurityToolkit) plugin. Over time you get a list like this.
If your website is on this list, though luck, your website (or it's security) sucks.

My favorite, easy to use and easy to maintain preferred DNS blocking tool is [NextDNS](https://nextdns.io/?from=xsddn7rw), but you can use this list with any other tool, such as PiHole or AdGuard for example.
